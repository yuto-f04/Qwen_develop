# 実験計画書

**研究タイトル**: 嘘を含む音声ガイドツアーがエンターテイメント体験に与える影響の検証  
**研究者**: 福田悠人（立命館大学）  
**作成日**: 2026-10-09  
**更新日**: 2026-11-03

---

## 1. 仮説

> 「嘘」がツアー内容の中に含まれているなら、ユーザのエンターテイメント体験は向上するのか？

---

## 2. 実験目的

Qwen3-TTS を用いた音声クローンによるキャンパスガイドツアーにおいて、
「真実のみ」の内容と「嘘を約30%含む」内容とを被験者に体験させ、
エンターテイメント体験（興味・おすすめ度・満足度・再参加意欲）に有意な差が生じるかを
定量・定性の両面から検証する。

あわせて、以下の副次的問いも探索する。

- どのような種類の嘘が「違和感」として気づかれやすいか
- 嘘への「違和感」を抱いた被験者のエンターテイメント体験は向上するか
- 順番効果（A→B か B→A か）がエンターテイメント体験の評価に影響するか

---

| 項目 | 内容 |
|------|------|
| 対象 | 立命館大学の学生・関係者 |
| 人数 | 合計 20 名（各グループ 10 名） |

## 4. 実験条件（独立変数・従属変数）

### 実験計画

**被験者内計画（within-subjects）** を採用する。  
各被験者は条件A・条件Bの**両方**を体験し、順番効果を相殺するためグループを2つに分ける。

| グループ | 1回目 | 2回目 | 人数 |
|---------|-------|-------|------|
| グループ1 | 条件A（真実） | 条件B（嘘あり） | 10名 |
| グループ2 | 条件B（嘘あり） | 条件A（真実） | 10名 |

> 被験者内計画を採用した理由：個人差（もともと面白いと感じやすい人かどうか）を
> 同一人物の2条件比較で取り除けるため、少人数でも効果量を検出しやすい。
> キャリーオーバー効果はグループの割り付け順序を逆にすることで統計的に確認・補正する。

### 独立変数（操作変数）

| 条件 | 内容 | 嘘の割合 |
|------|------|---------|
| **条件A（統制）** | 全部「真実」のツアー | 0% |
| **条件B（実験）** | 嘘を含む台本のツアー | 全体 30.3% |

### 従属変数（測定項目）

1〜10点のスケール（10点満点）で測定する。

| 内部名 | 質問内容 | 備考 |
|--------|----------|------|
| interest | ツアー内容に興味を持ちましたか？ | エンタメ得点構成 |
| length | ツアーの長さは適切でしたか？ | 条件確認 |
| clarity | ツアー中の説明は分かりやすかったですか？ | 条件確認 |
| enthusiasm | ガイドの語りに熱意を感じましたか？ | 条件確認 |
| recommend | このツアーを他人におすすめできますか？ | エンタメ得点構成 |
| expectation | ツアーは期待通りでしたか？ | 副指標 |
| satisfaction | このツアーに満足しましたか？ | エンタメ得点構成 |
| difficulty | ツアー内容は難しいと感じましたか？ | 条件確認（低いほど良い） |
| physical | 体力面で不安は感じましたか？ | 条件確認（低いほど良い） |
| revisit | また参加したいと感じましたか？ | エンタメ得点構成 |
| discomfort | 説明の中に「違和感」「気になったところ」はありましたか？ | なかった／少しあった／あった |
| discomfort_where | どこで「違和感」を感じたか？ | 自由記述 |
| discomfort_why | なぜ「違和感」を抱いたのか？ | 自由記述 |
| discomfort_interest | その違和感に「興味」を抱いたか？ | はい／いいえ |

### 主指標：エンタメ体験得点

interest・recommend・satisfaction・revisit の4項目の平均を **エンタメ体験得点** と定義する。  
Cronbach's α が 0.70 以上であれば4項目平均を、一方でも 0.70 未満であれば satisfaction（満足度1項目）を主指標とする。

### 統制変数

| 項目 | 固定値 |
|------|--------|
| 音声 | 毛利蘭（声優：山崎和佳奈）のゼロショット音声クローン（Qwen3-TTS） |
| 巡回施設 | H棟3施設（H121シアター教室 → KOBO → イノベーションラウンジ） |
| ツアー時間 | 約20分 |
| 再生デバイス | 同一のスマートフォン＋イヤホン（または共通スピーカー） |
| ガイダンス順序 | H121 → KOBO → イノベーションラウンジ の固定順 |

## 6. 実験の流れ（手順）

```
【当日手順】

STEP 0｜同意取得（約5分）
  ・「音声ガイド付きキャンパスツアーに関する研究」の概要を説明
  ・同意書にサインをもらう（嘘の有無は未開示）

      ↓

STEP 1｜1回目のツアー実施（約20分）
  ・グループに応じた条件（A or B）の音声ガイドを再生
  ・H121 → KOBO → イノベーションラウンジの順に移動

      ↓

STEP 2｜1回目のアンケート回答（約10分）
  ・Googleフォームで全項目に回答（「3. 何回目の参加ですか？」→「1回目」）

      ↓

STEP 3｜2回目のツアー実施（約20分）
  ・もう一方の条件の音声ガイドを再生（同じ施設を再訪）

      ↓

STEP 4｜2回目のアンケート回答（約10分）
  ・同じGoogleフォームで全項目に回答（「3. 何回目の参加ですか？」→「2回目」）

      ↓

STEP 5｜デブリーフィング（約5分）
  ・条件Bのツアーに意図的な嘘が含まれていたことを説明
  ・嘘の内容（11か所）を開示
  ・質問受付
```

> アンケートは同一のGoogleフォームに2回回答する（1人2回答、合計40行が理想）。  
> 1回目と2回目の回答は「氏名」で突き合わせる。

## 7. 評価方法・分析方法

### 主指標の検定

- **ウィルコクソンの符号順位検定**（両側、有意水準 α=0.05）
  - 同じ人の条件B − 条件A の差を検定する
  - 同点の人は計算から除き、除いた人数を報告する（zero_method="wilcox"）
- 報告する値：使用人数、同点人数、統計量 W、p値、効果量 r（=|Z|/√N）、Cohen's dz、差の平均・中央値・SD、95%信頼区間

### 副指標・補足分析

| 分析内容 | 方法 |
|----------|------|
| 副指標5項目（interest / recommend / satisfaction / revisit / expectation） | ウィルコクソン＋Holm補正 |
| 1回目だけの条件A vs 条件B | マン・ホイットニー U 検定＋Cliff's δ |
| 順番の影響（1回目 vs 2回目） | ウィルコクソン |
| 嘘への違和感と主指標の差の関係 | マン・ホイットニー U 検定 |
| 条件の確認（length / clarity / enthusiasm / difficulty / physical） | 効果量 dz（0に近いことを確認） |

> **分析方針**：サンプルサイズの制約（n≈20）から統計的検出力が十分でないため、
> p値だけで結論づけない。効果量（r、dz）を重視し、
> r=0.1（小）・0.3（中）・0.5（大）、dz=0.2（小）・0.5（中）・0.8（大）を目安とする。
> 「効果がない」とは書かず、「仮説を支持する結果は得られなかった」と表現する。

### 定性分析

- 自由記述（どこで違和感を感じたか・なぜ違和感を抱いたか）を、嘘11か所のIDに対応づけてコーディングする
- コーディングシートは `output/analysis/coding_sheet.csv` で管理し、研究者が手動で分類する
- 「違和感を感じた嘘ID」ごとの気づき人数・興味を抱いた人数を集計する

## 11. 期待される結果と考察の方向性

### 期待される結果

- 条件B（嘘ツアー）のエンタメ体験得点が条件A（真実ツアー）より有意に高い
- 嘘への違和感を「少しあった/あった」と回答した人のほうが、「なかった」人より B−A の差が大きい
- 順番効果は小さく、グループ1・グループ2で B−A の差に有意な違いがない

### 仮説が支持されない場合の考察

- 嘘の比率が高すぎる（KOBO: 56.5%）と不信感が生じた可能性
- 被験者内計画の性質上、2回目のツアーへの慣れ・飽きが評価を下げた可能性
- エンタメ体験得点の Cronbach's α が低い場合は satisfaction 1項目で再評価する
