# 実験計画書

**研究タイトル**: 嘘を含む音声ガイドツアーがエンターテイメント体験に与える影響の検証  
**研究者**: 福田悠人（立命館大学）  
**作成日**: 2026-10-09

---

## 1. 仮説

> 「嘘」がツアー内容の中に含まれているなら、ユーザのエンターテイメント体験は向上するのか？

---

## 2. 実験目的

Qwen3-TTS を用いた音声クローンによるキャンパスガイドツアーにおいて、
「真実のみ」の内容と「嘘を約30%含む」内容とを被験者に体験させ、
エンターテイメント体験（面白さ・没入感・驚き・満足度）に有意な差が生じるかを
定量・定性の両面から検証する。

あわせて、以下の副次的問いも探索する。

- どのような種類の嘘が「信じやすい」と感じられるか
- どのような種類の嘘が「面白い／エンターテイメント的」と感じられるか
- 嘘の比率（施設別：H121=38.9%、KOBO=56.5%、ラウンジ=29.6%）と面白さの相関

---

## 3. 実験対象（被験者）

| 項目 | 内容 |
|------|------|
| 対象 | 立命館大学の学生・関係者 |
| 人数 | 各条件 10 名以上（合計 20 名以上を目標、欠員見込みで 25 名程度に声がけ推奨） |
| 前提条件 | 実験対象施設（H棟）について事前に詳細な知識がないこと |
| 除外条件 | 映像学部所属など、H121・KOBO・イノベーションラウンジを日常的に使用している者 |
| インフォームドコンセント | 実験前に研究目的の一般概要を説明し同意を得る（「嘘が含まれている可能性」は実験後に開示） |

---

## 4. 実験条件（独立変数・従属変数）

### 独立変数（操作変数）

| 条件 | 内容 | 嘘の割合 |
|------|------|---------|
| **条件A（統制群）** | 全部「真実」のツアー | 0% |
| **条件B（実験群）** | 研究で作成した台本（嘘を含む）のツアー | 全体30.3% |

> **被験者間計画（between-subjects）を採用する。**  
> 各被験者はどちらか一方の条件のみを体験する。  
> 理由：同一人物が両方のツアーを体験すると、先に体験した内容が後の評価に影響するため（キャリーオーバー効果の排除）。

### 従属変数（測定項目）

| 測定項目 | 尺度 |
|----------|------|
| 面白さ | 5段階リッカート |
| 没入感 | 5段階リッカート |
| 驚き・新鮮さ | 5段階リッカート |
| 音声ガイドへの満足度 | 5段階リッカート |
| 説明の信頼感 | 5段階リッカート |
| 事実と異なる情報が含まれていたと思うか（条件A・B共通） | 3択（思わない／少し思う／強く思う） |
| 嘘を見抜けたか（実験群のみ） | 3択（気づかなかった／なんとなく気づいた／はっきり気づいた） |
| どこで気づいたか（実験群のみ） | 自由記述 |
| 全体的な感想 | 自由記述 |

### 統制変数（固定する条件）

| 項目 | 固定値 |
|------|--------|
| 音声 | 毛利蘭（声優：山崎和佳奈）のゼロショット音声クローン（Qwen3-TTS） |
| 巡回施設 | H棟3施設（H121シアター教室 → KOBO → イノベーションラウンジ） |
| ツアー時間 | 約20分 |
| 再生デバイス | 同一のスマートフォン＋イヤホン（または共通スピーカー） |
| ガイダンス順序 | H121 → KOBO → イノベーションラウンジ の固定順 |

## 5. 実験設定（ツアー台本の詳細）

### 条件A：真実ツアー

各施設の公式情報・実際の用途のみで構成したガイド台本。

### 条件B：嘘ツアー（研究台本）

| 施設 | 嘘の比率 | 主な嘘の内容 |
|------|---------|------------|
| H121シアター教室 | 38.9% | 低周波脳波強制覚醒実験／特殊音波反射システム／背もたれ振動機構 |
| KOBO | 56.5% | 極秘プラスチック再資源化プラント／分子レベル分解→フィラメント変換／12:40開館の秘密（午前溶解処理） |
| イノベーションラウンジ | 29.6% | 地下サーバー排熱利用の巨大煙突／可動机・椅子の整流板機能 |
| **全体** | **30.3%** | 総文字数1,514字のうち458字が嘘 |

> 嘘の設計方針：アンケート調査の結果、「信じやすい嘘」の特徴として
> 「具体的数値の提示」「既知の企業名・部分的事実の混在」「最新用語の使用」が有効であることが
> 事前調査で判明しており、これらを意図的に取り入れている。

## 6. 実験の流れ（手順）

```
【事前準備】
  ・被験者を条件A / 条件Bのいずれかに無作為に割り付ける
  ・音声再生デバイスを統一し、バッテリー・音量を確認する
  ・台本から生成した完成音声（tour_guide.wav）を端末に準備する

      ↓

【当日手順】

STEP 0｜同意取得（約5分）
  ・「音声ガイド付きキャンパスツアーに関する研究」の概要を説明
  ・同意書にサインをもらう（嘘の有無は未開示）

      ↓

STEP 1｜ツアー実施（約20分）
  ・H121シアター教室 → KOBO → イノベーションラウンジの順に移動
  ・各施設で音声ガイドを再生（被験者はイヤホンで聴く）
  ・施設内での行動制限なし（見渡してよい）

      ↓

STEP 2｜施設ごと即時アンケート（任意）
  ・各施設の説明直後に、その施設に関する印象を1〜2問だけ簡易記録する
  ・目的：施設別の面白さと嘘比率の相関を分析するため

      ↓

STEP 3｜総合アンケート（約10分）
  ・ツアー全体の評価（面白さ・没入感・驚き・満足度・信頼感）を5段階で回答
  ・実験群（条件B）のみ：嘘に気づいたかどうか、どこで気づいたかを回答

      ↓

STEP 4｜デブリーフィング（約5分）
  ・実験群（条件B）の被験者に、ツアー内容に意図的な嘘が含まれていたことを説明
  ・統制群（条件A）の被験者にも研究全体の目的を説明
  ・質問受付

STEP 5｜事後追加アンケート（実験群のみ・約2分）
  ・「嘘が含まれていたと知った今、ツアーの面白さはどう感じますか？」（5段階）
  ・目的：「嘘を知る前 vs 知った後」の評価変化を分析し、
    嘘の存在そのものがエンターテイメント性に寄与するかを検証する
```

## 7. 評価方法・分析方法

### 定量分析

| 分析内容 | 主指標 | 補助指標 |
|----------|--------|---------|
| 条件A vs 条件B の各指標の差 | **効果量（Cohen's d）** | Mann-Whitney U 検定の p値 |
| 施設別嘘比率と「面白さ」の相関 | **Spearman の順位相関係数** | — |
| 嘘に気づいたかどうかと面白さの関係 | **クロス集計（割合の比較）** | χ²検定の p値 |

> **分析方針**：サンプルサイズの制約（各群 n≈10）から統計的検出力が十分でないため、
> p値のみで結論づけることはしない。効果量（Cohen's d）を主指標とし、
> d=0.2（小）・0.5（中）・0.8（大）を目安に効果の大きさを評価する。
> Mann-Whitney U 検定はノンパラメトリック検定として補助的に実施し、方向性の確認に用いる。

### 定性分析

- 自由記述の回答を読み、似た内容ごとにラベルを貼ってグループ分けする
- 「面白いと感じた理由」「嘘に気づいたきっかけ」のパターンを抽出する
- 嘘の種類（極端表現・数値・専門用語）との対応を考察する

### 評価軸の定義

| 軸 | 質問文（例） | 尺度 |
|----|------------|------|
| 面白さ | 「このツアーガイドの説明は面白かった」 | 1（全くそう思わない）〜 5（とてもそう思う） |
| 没入感 | 「説明を聞きながら施設に引き込まれる感覚があった」 | 1〜5 |
| 驚き | 「知らなかった情報を聞けて驚いた」 | 1〜5 |
| 満足度 | 「このツアーに参加して良かった」 | 1〜5 |
| 信頼感 | 「ガイドの説明内容は信頼できると感じた」 | 1〜5 |

## 8. 倫理的配慮

| 項目 | 対応 |
|------|------|
| インフォームドコンセント | 研究目的を説明し、書面で同意を得る |
| 嘘の開示 | 実験終了後（デブリーフィング時）に、実験群の被験者に嘘の内容を全て開示する |
| 参加の自由 | 途中でツアーを中断・辞退できることを事前に伝える |
| 個人情報 | アンケートは匿名で行い、個人を特定できないよう管理する |
| データ管理 | 取得したデータは研究目的にのみ使用し、第三者に提供しない |

## 11. 期待される結果と考察の方向性

### 期待される結果

- 条件B（嘘ツアー）の「面白さ」「驚き」スコアが条件A（真実ツアー）より有意に高い
- 嘘の比率が高い KOBO（56.5%）での面白さが最も高く、低い施設より高スコアになる
- ただし「信頼感」スコアは条件Bで低くなる可能性がある

### 仮説が支持されない場合の考察

- 嘘の比率が高すぎる（KOBO: 56.5%）と、不信感やシラケが生じている可能性
- 先行アンケートでの最適比率「10〜30%」と実際の台本比率（全体30.3%）との関係
- 嘘を見抜けた被験者と見抜けなかった被験者で面白さに差がある場合、「見抜く楽しさ」がエンターテイメント性に寄与する可能性
